About this tool

QR codes bridge print and digital: menus, business cards, event posters, Wi-Fi sharing, and payment links all work better scannable. This generator turns any URL or text into a crisp QR code right in your browser, with adjustable size and instant preview.

The code is generated locally — your URL is never sent to a server or logged — and downloads as a clean PNG with no watermark, ready for print or web.

How to use

  1. Type or paste your URL or text into the input box.
  2. Choose the image size (small for screens, large for print).
  3. Preview the QR code and test-scan it with your phone.
  4. Click Download to save it as a PNG.
