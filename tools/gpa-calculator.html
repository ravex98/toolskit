GPA Calculator

Enter courses with letter grades and credits to compute your GPA on the 4.0 scale.

Loading tool…

About this tool

On the 4.0 scale, each letter grade maps to grade points (A = 4.0, B = 3.0, and so on), and each course is weighted by its credit hours. Add your courses with their grades and this calculator handles the weighted average.

The built-in grade table shows the point value of every grade from A+ to F, so there is no need to look anything up.

How to use

  1. Add each course with its credit hours.
  2. Select the letter grade earned for each course.
  3. Read your GPA on the 4.0 scale.
